# 安全与隐私约束

- 仅对自己拥有或明确授权的设备执行 `probe`；工具强制限定 RFC1918 私网单个 IPv4 地址，默认 6 个 TCP 端口，只做连接测试。
- 不扫描整个小区/公司网段，不爆破口令，不尝试未知厂商接口的写操作。
- 不公开 `.mi.token`、Cookie、`MI_USER`、`MI_PASS`、设备 DID、MAC、序列号、家庭 Wi-Fi、IP、语音记录、抓包原始内容。
- 建议使用环境变量管理账号凭据。上游应用产生的 token 缓存及运行日志位于其自身目录；运行前确认 `.gitignore`，必要时保存于仓库外。
- 向他人反馈日志前，人工检查用户名、手机号、设备 DID、口令、token、IP 与语音文本。
- 不要为排障关闭小米账号安全验证；使用官方验证流程或查看上游 issues。
- M4 硬件阶段必须先确认 GND / TX / RX 的引脚定义与逻辑电平，切忌将 USB-TTL 接至 12V 电源引脚；优先不焊接、不改写。
- 公开脚手架不接管电脑的任意命令执行。未来 Agent tool 必须设计白名单、二次确认和权限隔离。
