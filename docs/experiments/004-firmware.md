# 实验 004：L05C NuttX / 固件 / UART（研究草案）

**当前状态：仅研究规划，尚未拆机，未读取固件，未证明存在可用 UART 控制台。**

1. 从设备和公开资料整理芯片、存储介质、固件版本、更新机制；为每项写明证据来源。
2. 公开资料参考： https://github.com/duhow/xiaoai-patch （该项目明确不支持 L05C 刷机补丁）及其 `research/updates.md`。
3. 对获得合法访问权限的公开固件做离线 `file`、哈希及静态分析；不推断未证实的内存布局，不直接烧写。
4. 如果未来拆机，先留存 PCB 高清照片，确认电源已断开；用万用表确认 GND 与信号电平。必须区分设备 12V 供电口和 UART TTL 电平，USB-TTL 不接 VCC。
5. 无论有无 UART，都应记录 boot log 证据与负面结果。**没有可用 UART 不影响 M1 AI 闭环。**
